Desde o início do ano trabalho com **Playwright** e **CI no GitHub Actions**, e venho implementando automação E2E em um ERP web empresarial.

- 🔭 Atualmente: automação de testes de API e UI integrada ao pipeline de CI

- 💬 Posso ajudar com: testes manuais, testes de API, Postman, mapeamento de cenários de teste, Azure DevOps e automação E2E

### 🧪 Como valido software

- Parto do requisito e sigo o fluxo completo até o endpoint, para reportar bugs com contexto real
- Uso IA para analisar tickets e gerar casos de teste, sempre revisando o resultado
- Em entregas com código gerado por IA, confirmo a regra de negócio manualmente
